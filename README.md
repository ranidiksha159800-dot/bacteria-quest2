# Microbe Lab: Ecology Quest

An interactive browser game on microbial ecology: interactions, adaptations and environmental dynamics.

- 3 habitats (marine, freshwater, terrestrial), 15 challenges
- Interaction diagrams (mutualism, commensalism, amensalism, predation, parasitism)
- Habitat zone placement, a lake eutrophication slider and a tappable nitrogen cycle
- Ecosystem health bar, streak bonus, exit button and a full scorecard

## Run locally
Download `index.html` and open it in any modern browser.

Built for BTY323 Microbiology (Unit V).
